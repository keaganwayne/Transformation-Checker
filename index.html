3 Rule reference

Translation(x, y) → (x + h, y + k)
h moves left/right. k moves up/down.
Reflect across x-axis(x, y) → (x, −y)
Reflect across y-axis(x, y) → (−x, y)
Reflect across y = x(x, y) → (y, x)
Reflect across y = −x(x, y) → (−y, −x)
Rotate 90° CCW(x, y) → (−y, x)
Rotate 90° CW(x, y) → (y, −x)
Rotate 180°(x, y) → (−x, −y)
